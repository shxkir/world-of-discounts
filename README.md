# World of Discounts

Local retail website for **World of Discounts**, 96 Oxford St, Cambridge Park NSW 2747.

All owner-updatable facts live in `data/world-of-discounts.ts`. Add a logo, photos, products, prices, hours, and social links there when the store supplies them.

## Content rules

- Do not invent prices. Use `PRICE IN STORE` or `COMING SOON`.
- Do not invent weekly opening hours. Keep `hours.weekly` empty until a real schedule is supplied.
- Do not invent review quotes. Add `reviews` only when the exact wording is available.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
